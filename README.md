# Online Continuous Emission Monitoring System (OCEMS)

## 📌 Project Overview

The **Online Continuous Emission Monitoring System (OCEMS)** is a real-time environmental monitoring solution designed to continuously measure and analyze pollutants released from industrial sources.

The system provides reliable emission data, real-time monitoring, automatic alerts, historical data analysis, and reporting support for environmental compliance.

## 🎯 Objectives

* Continuously monitor industrial emissions.
* Measure multiple gaseous and particulate pollutants.
* Provide real-time emission data.
* Generate alerts when emission levels exceed configured limits.
* Store historical monitoring data.
* Support remote monitoring and analysis.
* Reduce manual monitoring and maintenance requirements.

## ✨ Key Features

* Real-time continuous emission monitoring
* Multiple pollutant measurement
* Automatic data logging
* Online/web-based monitoring
* Configurable alarm and alert system
* Historical data analysis
* Automated reporting
* Calibration support
* Low-maintenance operation
* Scalable monitoring architecture

## 🌫️ Monitored Parameters

The system can monitor:

* SOx
* NOx
* CO₂
* CO
* O₃
* SPM
* HCl

| Parameter | Measurement Range |
| --------- | ----------------: |

| O₃        |         0–300 ppm |
| SPM       |      0–1000 µg/m³ |

*Measurement ranges may vary according to the selected sensing configuration and calibration.*
